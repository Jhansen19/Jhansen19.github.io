Decision summary

updates with the weights
Analyst's read (base weights). Empagliflozin leads on balance: a large, growing pool with the entry window still ahead, which leaves time to prepare. Apixaban is the biggest prize but the most contested and still in litigation, so it advances only behind an SPC-clearance gate. Edoxaban is the winnable niche: a smaller pool, few expected entrants and a clean fit. All of the top five sit in cardiovascular or cardiometabolic care, so the portfolio question is concentration: sequencing launches across 2027 to 2030 spreads capacity, but not therapy-area risk.

Scoring rules

CriterionInputsRule (1–5)
Market attractivenessEU sales, market growthSales ≥ €2,500m = 5, ≥ 1,500 = 4, ≥ 800 = 3, ≥ 400 = 2, else 1; +1 if growth ≥ 8%, −1 if growth < 0; capped 1–5.
Commercial potentialEU sales, price erosion, attainable shareMidpoint revenue = sales × (1 − erosion) × share. ≥ €25m = 5, ≥ 15 = 4, ≥ 8 = 3, ≥ 4 = 2, else 1.
Strategic fitTherapy-area fit, channelAverage of area fit (1–5) and channel fit (retail Rx 5, hospital 3, specialty 2), rounded.
Pipeline & timingLoE start / end vs today (Oct 2026)Window ended = 1; already open = 2; opens in < 1 yr = 4; 1–3 yrs = 5 (ideal prep time); 3–4 yrs = 3; > 4 yrs = 2.
Risk (inverse)Litigation, API suppliers, development complexityRisk points: litigation 0 / 1.5 / 3; API suppliers ≤ 2 = 1, 3–4 = 0.5, ≥ 5 = 0; complex product = 1. Score = 5 − points (rounded), min 1.
Competition (inverse)Expected generic entrants≤ 3 = 5, 4–6 = 4, 7–10 = 3, 11–15 = 2, > 15 = 1.
